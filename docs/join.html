Torn Shared ServerA player-run tool for Torn. Not part of Torn.

Lend a Public key

A Public Only key helps our server keep up with public Torn data. It is the weakest key Torn makes: it reads only what any player can already see, and it can change nothing.

What your key does
Our server uses it to read public Torn data, the kind any player can look up, to keep our own tools up to date.
What it can see of you
Your Torn name and ID, so we know whose key it is. Nothing else: a Public Only key cannot read your items, money, log or messages, and we refuse any stronger key.
What it costs you
Up to 30 of your 100 requests a minute, day and night. If Torn ever answers "too many requests" on your key, we slow down.
How to leave
Paste the key under "Remove my key" below: it is taken out at once, with everything held for it. Or delete the key in Torn: the server takes it out the next time it would have used it.
